- `npm test`：路由、WXML 绑定、主包体积、公共文案、隐私边界、V2 回归、Product v0 运行时和云端生命周期全部通过。

- 此前 DevTools 体验版上传实测：`1,214,992 bytes`（约 `1.2 MB / 2 MB`），已成功上传版本 `3.0.0`；包含本次补齐的 TDesign 运行时依赖。本轮人工回归后的布局修订已重新执行 `build-npm`，尚未重新上传新的体验版。
- `FEATURES.v3ProductV0 = true`，`v3ProductPreview = false`，`v3CalibratedProduction = false`。

## 本轮人工回归（2026-08-29）

- 微信开发者工具中已检查 iPhone 15 Pro Max（430px）和 iPhone 5（320px）两种宽度：首页首次/恢复态、方法说明弹层、答题首题、选中反馈和下一题布局。
- 已确认恢复态显示 `1 / 266` 与 `<1%`，答题页不会重复整段介绍；长题干、选项和固定底部操作栏之间没有相互遮挡。

- 结果页已完成结构性布局修复并通过合成 persona/路由测试；尚未用真实 266 题逐题走完结果页，也尚未替代真机 Android/iOS、弱网和云权限验收。

## 发布前必须在微信工具/真机完成

1. 登录微信开发者工具，打开当前 AppID 项目，执行“工具 → 构建 npm”。
2. 本次已执行 `npm run deploy:cloud`，`assessmentService`、`participantService`、`interviewOps`、`datingProfile` 四个云函数均上传成功；若后续修改云端源代码，重新执行并确认四项均为成功。
3. 在 iPhone 小屏、普通 Android 和窄屏设备各走一次：首次进入、选择题、多选题、数字/文本题、失焦保存、返回继续、章节切换、完成报告、依据页、修改回答、重新回答和删除结果。
4. 断网完成一部分回答，退出后恢复网络并重新进入，确认本机答案仍在且能同步；再从另一台设备确认云端恢复。
5. 在云开发控制台确认十个集合均为客户端不可读、不可写；测试删除后确认本人的 session、report 和反馈记录已清理。
6. 在微信后台核对隐私政策、运营主体、保存期限、用户权利和客服入口，再提交体验版或审核版。

## 当前外部阻塞

代码、主包和云函数的自动验证已完成，且已有版本 `3.0.0` 体验版上传记录；本轮最新布局修订尚未重新上传。剩余是微信工具/真机与后台的人工验收：真实设备回归、云开发权限核对、隐私资料核对，以及提交体验版/审核版。

正式发布仍需要微信后台的人工审核/提交动作，这不由仓库脚本代替。
